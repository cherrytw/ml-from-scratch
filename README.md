# Machine learning from scratch

The steps, commands and code for **Machine learning from scratch**, a
hands-on YouTube series by [MP_Studio](https://www.youtube.com/@mpstudioapp).
Each episode follows one project from a question to its answer, with real
code you can run along.

Each episode has its own folder:

- `README.md`: every step and command from the video, with screenshots;
- `environment.yml`: the exact versions the episode used;
- from episode 1 on, the episode's notebook.

## Start here

[Episode 0](00-setup) sets up your computer: conda, a box (a conda
environment) called `ml` with Python and the series' tools, and your first
notebook. Every later episode starts from there:

```sh
conda activate ml
jupyter lab
```
